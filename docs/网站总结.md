# 宁夏文旅指南 · 网站总结

> 版本：v0.2（完成前端视觉改造）
> 更新时间：2026-11
> 代码位置：`D:\dsh`　预览：`http://127.0.0.1:3001`

## 一、一句话

一个关于宁夏文旅的中文信息站：把散落在公开渠道的景区、美食、路线与方言资料，整理成**可查、可排、可问**的形态；不依赖数据库、地图 SDK、外部图床或大模型密钥即可完整运行。

| --- | --- |

## 三、五个功能模块

| 模块 | 能做什么 | 技术要点 | 局限 |
| --- | --- | --- | --- |
| 景区介绍 | 10 个景区，按区域/类型筛选、地图条带联动、详情页含亮点/门票/交通/坐标 | 服务端静态生成 + JSON-LD `TouristAttraction` | 门票时间非实时，标注「待核实」 |
| 美食推荐 | 20 道地方菜，按区域分组、口味标签、与景区互链 | 与景区数据双向配对（`pairWith`） | 不收录具体商户，避免过期与广告 |
| 路线设计 | 8 条精品路线 + 规划器：按天数/区域/兴趣/预算生成逐日行程 | 纯函数规则引擎：区域聚拢 → 兴趣打分 → 自北向南排序 | 规则建议，非最优解；不含实时路况 |
| 方言翻译 | 普通话⇄银川话双向翻译，160 条词条带读音/例句/区域/置信度 | 最长匹配 + 区域偏好 + 单字限制 | 汉字记音、拼音近似，非国际音标 |
| AI 问答 | 只答站内资料，答案附引用，超纲直接拒答 | bigram + BM25 检索、覆盖率阈值、同义词扩展 | 浏览器本地抽取式回答；可接独立外部 API |

## 五、内容与数据

**实体（`src/types/content.ts`）**

- `Attraction`：slug、名称、区域、类型、简介、亮点、开放时间、门票、交通、最佳季节、坐标、标签、来源、待核实标记。
- `Food`：slug、名称、区域、简介、故事、口味标签、价格区间、配对景区。
- `TravelRoute` + `RouteDayPlan`：天数、主题、覆盖区域、逐日行程（时段/地点/类型/关联 slug）、预算。
- `DialectEntry` + `DialectExample`：普通话、方言、读音、区域、类别、说明、置信度、例句。
- `Citation`：来源标识、标题、链接。

**内容规模**：10 景区 / 20 美食 / 8 路线 / 160 方言词条（问候 10、时间 20、饮食 20、日常 30、人物 25、程度 20、动作 20、语气 15）。

**来源与可信度机制**

- 每条内容带 `sources` 与 `verified`；全站默认 `verified: false`，页面显示「待核实」。
- 方言额外标注区域与置信度（3 较可靠 / 2 一般 / 1 存疑），并明确写明「宁夏话内部不统一」。
- 待核实明细见 [内容待核实清单](./内容待核实清单.md)。

## 六、技术架构

```
页面（Server Components 为主）
├─ 列表/详情：直接读 src/content（构建期静态化）
├─ 交互区（Client）：筛选、规划器、翻译器、对话
└─ 客户端交互
   ├─ 问答 → 本地检索（或可选外部 API）→ 答案 + 引用
   └─ 方言 → 词典最长匹配 → 译文 + 分段置信度
```

- **检索**：中文 bigram 分词 + BM25；同义词扩展（小孩→亲子、票价→门票）；覆盖率按「多字词命中数 / 多字词总数」计算，低于 0.2 或分数不足即拒答，避免硬答。
- **规划器**：按区域聚拢候选 → 兴趣标签打分 → 最多铺开 3 个区域 → 按自北向南顺序分配天数 → 每天 2 个同区域景区 + 1 顿当地饭；无匹配时逐级放宽并给出提示。
- **方言**：双向词典按区域偏好排序，最长匹配优先，单字仅在整句输入时匹配，未收录片段原样保留并提示。
- **外部 API**：默认不发布用户问题；如设置 `NEXT_PUBLIC_API_BASE_URL`，问答请求独立服务，密钥与限流由该服务管理。
- **静态部署**：`next build` 输出 `out/`，GitHub Actions 自动发布到 Pages。
- **无外部请求**：构建与运行都不请求图床、字体 CDN、地图服务。

## 七、设计与交互

方向为「朔方纪行 · 旅行志 / 印刷品」：

- 纸色 `#f3ebdc` + 墨 `#17120e` + 朱砂 `#b23a24` + 石青 `#2c5a57`；颗粒纹理点缀。
- 宋体大标题（大字号、字距）+ 无衬线正文 + 等宽体做编号与元信息。
- 直角、细线分隔、双线「图版」、印章字标；目录式索引、编号章节、页首巨型浅色底纹字。
- 景区卡、美食条目、路线卡是三种不同结构，避免统一卡片流。
- 移动端：抽屉式目录、单列版面，10 个页面横向溢出均为 0。

## 十、已知限制

1. 内容全部「待核实」：门票、开放时间、交通为公开资料整理，非实时。
2. 无地图 SDK：地图是自北向南的条带示意，不含导航、距离与路径规划。
3. 图片本地托管：首页、景区与美食页使用 Wikimedia Commons 开放许可实拍，作者和许可见 `/about`。
4. 方言为汉字记音 + 拼音近似，且「宁夏话」内部差异大，已按区域与置信度标注。
5. AI 问答未接入真实大模型（无 key），当前为本地检索与抽取式回答。
6. 未做用户系统、评论、支付。
7. 默认使用浏览器本地问答；如需 LLM 与共享限流，需要独立部署外部 API。
