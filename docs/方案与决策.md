# 建站方案与关键决策（ADR 摘要）

> 项目：宁夏文旅指南（`D:\dsh`）
> 目标：五大模块可用（景区、美食、路线、方言、AI 问答），移动端优先，无外部密钥即可运行。

## 1. 范围

- 本次交付：可本地运行的完整站点 + 静态构建 + GitHub Pages 自动部署配置。
- 不在本次范围：自定义域名、ICP/公安备案、外部 API 服务、CDN、真实大模型调用、语音朗读、用户系统、支付。

## 2. 关键决策

| 决策 | 选择 | 理由 | 备选与代价 |
| --- | --- | --- | --- |
| 框架 | Next.js 15 App Router + TS | SSR/SSG 利于 SEO，前后端同仓库，部署简单 | Vite SPA：SEO 弱；Nuxt：团队更熟 Vue 才划算 |
| 样式 | Tailwind v4 + 手写组件 | 无 CLI 交互、依赖少、可控 | shadcn/ui：设计更统一但要跑交互式初始化 |
| 数据 | TypeScript 内容模块 | 零运维、构建期类型校验、离线可用 | PostgreSQL + Prisma：内容需多人编辑时才值得 |
| 检索 | bigram + BM25（纯 TS） | 无外部服务、可测试、中文短查询够用 | pgvector/Meilisearch：语料上千条后再换 |
| AI | 浏览器本地检索 + 可选外部 API | 静态 Pages 无需 key 即可工作 | 直接调前端 LLM：会暴露密钥 |
| 地图 | 自绘 SVG 五市示意图 | 不依赖高德/腾讯 key 与商用授权 | 高德 JS API：需 key、配额与授权评估 |
| 图片 | 本地写实摄影 | 兼顾真实感、授权透明与静态部署 | Wikimedia Commons 开放许可照片，站内 `/about` 署名 |
| 字体 | 系统字体栈 | 国内访问 Google Fonts 不可靠 | 自托管字体：增加体积与授权成本 |
| 方言 | 人工词典 + 最长匹配 | 可控、可解释、可标注置信度 | LLM 直译：无 key 不可用且不可控 |

## 3. 架构

```
页面（Server Components）
  ├─ 列表/详情：直接读 src/content
  ├─ 交互区（client）：筛选、规划器、翻译器、对话
  └─ 客户端交互
      ├─ 问答 → 浏览器本地检索（或可选外部 API）→ 答案 + 引用
      └─ 方言 → 浏览器内词典最长匹配 → 译文 + 分段置信度
```

- 检索与规划器均为纯函数，便于单测，不依赖网络。
- 外部 API 的密钥只保存在该独立服务中，不进入 GitHub Pages。
- 静态部署：`next build` 输出 `out/`，默认不依赖服务端限流。

## 4. 验收结果（本次）

- `vitest run`：4 个测试文件、35 个用例全部通过。
- `next build`：通过（静态生成 52 个页面 + 类型检查）。
- 截图：`docs/screenshots/`，桌面 1440×900 与移动 390×844 各 10 个页面，另含规划器/问答的交互结果图。
- 移动端横向溢出检查：10 个页面全部为 0。
- 无外部请求：无图床、无地图 SDK、无字体 CDN。
- 浏览器实测：9 个页面、规划器、站内问答引用和方言翻译正常。

## 6. 视觉改造（第二轮）

原始版本是常见的「圆角卡片 + 浅色渐变 + 无衬线标题」模板感。第二轮整体改为**旅行志/印刷品**方向，规则如下：

| 维度 | 旧 | 新 |
| --- | --- | --- |
| 隐喻 | 旅游 App 卡片流 | 朔方纪行 · 旅行志 / 印刷图版 |
| 色彩 | 沙色 + 柔和渐变 | 纸色 `#f3ebdc` + 墨色 `#17120e` + 朱砂 `#b23a24` + 石青 `#2c5a57` |
| 字体 | 无衬线为主 | 宋体做标题（大字号、字距），无衬线做正文，等宽体做元信息/编号 |
| 形状 | 大圆角、投影 | 直角、细线分隔、内缩双线图版 |
| 版面 | 居中卡片网格 | 非对称栅格、目录式索引、编号章节、竖排点缀 |
| 图片 | 渐变占位块 | 实拍照片 + 纸面图版 + 颗粒纹理 + 经纬度标注（本地托管） |
| 交互 | 悬浮上浮 | 文字转朱砂、整行反色、印章微旋 |

组件层面：

- `src/app/globals.css`：新 token（paper/ink/line/vermilion/teal/ochre）、颗粒纹理、印章、竖排、首字下沉、滑杆样式。
- `SiteHeader`：上沿元信息条 + 印章字标 + 带序号导航（`01 首页`）。
- `SiteFooter`：墨色反白页脚，大字号字标。
- `PageHeader`：大标题 + 巨型浅色汉字底纹 + 英文小标。
- `cards.tsx`：景区「图版卡」、美食「菜单条目」、路线「天数侧栏」三种不同结构，避免统一卡片。
- `NingxiaMap`：改为自北向南的条带示意，替代首版有缝隙的多边形拼图。
- 问答答案增加轻量 Markdown 渲染（不再露出 `**`），分页/加载更多补上。

验收：35 个单测全绿、`next build` 通过、桌面 + 移动 22 张截图无横向溢出、控制台无错误。
